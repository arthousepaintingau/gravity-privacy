Privacy Policy

Gravity – File Organizer for Mac · Effective 19 November 2026

Gravity organizes folders on your Mac and keeps a local history so you can undo a run. It has no account and no network permission. File contents are handled on your Mac and are not sent to us.

This policy

This policy describes only Gravity – File Organizer, published by Babak Jahangirzadeh. It matches what this version of the app does.

When Gravity reads a folder

Gravity reads a folder when you drop one onto it, choose one, tidy Downloads, Desktop, or Documents, or when automatic tidying of Downloads is on. For each file it uses the name, extension, size, and file-system dates. In Downloads, and in a folder you drop or choose, it also looks inside subfolders. On the Desktop and in Documents it organizes loose files at the top and leaves existing folders where they are.

For a photo or screenshot, Gravity reads the capture date from the file when it is present: the original or digitized date, otherwise the TIFF date, otherwise a date written in the file name. To tell a screenshot from another picture, it also checks whether the photo’s comment says “screenshot”, or whether the file name starts with a screenshot name. For a video or screen recording, it reads the creation date stored in the file, or a date in the file name. It does not read location data from photos or videos. Every other file is dated from the earlier of its creation date and its modification date.

Apps, project folders, photo libraries, and other folders the app recognizes as belonging to another application are not split open. A folder name you add under Also Protect These Folders is remembered and left intact. Gravity stores that name, not the folder’s contents.

Names taken from a document

If a document’s name does not say what it is, such as “Scan_0012.pdf” or “Document (3).docx”, Gravity may read text from that file on your Mac and suggest a short title. This is limited to documents, not duplicates, and to PDF, plain text, Markdown, CSV, TeX, RTF, Word, and OpenDocument files. At most 150 documents are named this way in one run. Gravity reads up to the opening 2,000 characters. For a PDF it uses the text of the first three pages, or, if the PDF has no text layer, Apple’s on-device text recognition on the first page.

The first 1,000 characters of that excerpt are passed to the on-device language model built into macOS, and only when that model is available. The model is asked for a title of a few words. Gravity keeps the title as the new file name. It does not save the excerpt in History or in its settings. Gravity has no network permission, so it does not transmit the excerpt.

Duplicate files

Gravity computes a SHA-256 checksum of a file’s contents when another file in the same run has the same size. Packages and files that are not downloaded yet are not checksummed. The checksum is used only to decide which files match, during that run. It is not written into History.

What Gravity changes on disk

With Tidy the Folder Itself, Gravity copies files into a folder named Organized, then moves the previous contents into a folder named Original Files. With Leave Folder Untouched, the folder you chose stays as it is and the organized copy is saved in the location you set, which is Downloads unless you choose another folder.

If color-coding is on, Gravity sets Finder tags on the organized copies and on the folders it creates for them.

Clean Up is a separate action. It moves clutter and duplicates, both the organized copies and the matching originals, to the Trash. You can undo that run. Emptying the Trash is something you do yourself.

Undo puts moved items back, then deletes the copies and empty folders that the run created. Those copies are the ones Gravity made. Your originals are moved back rather than deleted.

What stays on your Mac

Gravity saves history in a file named History.json, in its Application Support folder, so a run can be undone after you quit. Each of up to 100 runs stores the date, whether it was automatic, the source folder’s name and path, the output folder’s path, the organize mode, the number of files, a count per category, and the paths of the items and folders the run created or moved, including a Trash path after Clean Up. It also stores a macOS security-scoped bookmark so Gravity can open that folder again. History does not include file contents, document excerpts, or checksums. Clear History erases this file’s entries.

Settings stored on your Mac are: tidy in place or leave the folder untouched, where organized copies are saved, whether to preview before organizing, whether to color-code in Finder, whether to tidy Downloads automatically, whether to show a Dock icon, whether the Gravity window is hidden, whether it stays above other windows, whether the welcome screen has been completed, and the extra folder names you protect. Access you grant to Desktop, Documents, or a chosen output folder is stored as a security-scoped bookmark. Open at Login is registered with macOS as a login item.

Automatic tidying

If you turn it on, Gravity watches the Downloads folder while the app is running. After Downloads has been quiet for about a minute and a half, it organizes that folder in place, without showing a preview first. Partial downloads, and files changed in the last minute, are left alone. The same run is recorded in History and can be undone. Turning the setting off stops the watch.

Permissions

Gravity runs in the Mac App Sandbox. It may read and write Downloads. Other folders are available only after you select them or drop them on the app. The shortcut Control-Option-G shows or hides Gravity. It does not record what you type.

What Gravity does not do

Gravity does not create an account and does not include analytics, advertising, or a third-party crash reporter. It is not permitted to open network connections. It does not use the Photos library, Contacts, or Calendar. It does not read photo or video location data. It does not send your files, file names, document text, checksums, or history to Babak Jahangirzadeh or to anyone else.

The App Store purchase

Gravity is a one-time purchase on the Mac App Store. Apple handles the payment. The app itself does not receive your payment card number or Apple ID.

Children

Gravity is a file utility for people organizing their own folders. It is not directed at children, and it has no account through which it could collect information about a child.

Your choices

You choose the folder. You can turn preview on or off, turn automatic tidying off, undo a run, and clear History. Deleting Gravity removes the app. History and settings for it remain in the app’s container until that container is deleted.
